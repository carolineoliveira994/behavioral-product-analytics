# 📊 Behavioral Funnel Analytics

Uma análise comportamental de usuários em jornadas de e-commerce utilizando Python, Streamlit e Plotly.

O projeto investiga por que usuários altamente engajados navegam pelos produtos, retornam à plataforma e ainda assim apresentam baixa conversão.

---

# 🎯 Objetivo

Entender padrões de comportamento em jornadas de compra digitais e identificar:

- onde ocorre o maior abandono
- sinais de intenção de compra
- impacto da recorrência de sessões
- comportamento exploratório dos usuários
- possíveis oportunidades de otimização do funil

---

# 🧠 Pergunta de Negócio

```text
Por que usuários altamente engajados não convertem?

📈 Principais Insights
